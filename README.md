# 🖼️ CodeAlpha_ImageGallery

A responsive image gallery built with HTML, CSS and vanilla JavaScript. It features category filters, a lightbox viewer with next/previous navigation, and keyboard support. This project was completed as part of the **CodeAlpha Frontend Development Internship**.

🔗 **Live demo:** https://shah-iqra.github.io/CodeAlpha_ImageGallery/

## ✨ Features

- 🎨 Responsive grid layout that adapts to desktop and mobile screens
- 🔍 Category filter (All / Nature / City)
- 🖱️ Smooth hover effects with zoom and lift animation
- 🔎 Lightbox viewer: click any image to view it full screen
- ⏮️ ⏭️ Previous and next navigation inside the lightbox (loops at the ends)
- ⌨️ Keyboard support: `←` `→` to navigate, `Esc` to close
- ❌ Close the lightbox by clicking the close button or the dark background

## 🛠️ Technologies Used

- **HTML5**: semantic structure with `<figure>` and `<figcaption>`
- **CSS3**: CSS Grid, transitions, hover effects and media queries
- **JavaScript (ES6)**: filtering, lightbox logic and keyboard events
